# Bundled Remotion fonts

These WOFF2 files keep composition discovery and parallel renders independent of remote font services. They are loaded by `remotion/src/fonts.ts` through `staticFile()`.

| Family | Source package | Version | Weights |
| --- | --- | --- | --- |
| Inter | `@fontsource/inter` | 5.3.0 | 400, 500, 600 |
| JetBrains Mono | `@fontsource/jetbrains-mono` | 5.3.0 | 400, 500, 700 |
| Source Serif 4 | `@fontsource/source-serif-4` | 5.3.1 | 600, 700, 900 |
| Space Grotesk | `@fontsource/space-grotesk` | 5.3.0 | 500, 600, 700 |
| Spectral | `@fontsource/spectral` | 5.3.0 | 500, 600 |

The original license notice from each package is preserved in `licenses/`.
