# Current short-form production direction

User direction for upcoming videos:

- Make **simple, engaging explainer videos** that clearly explain how something works.
- Stay with **Science and Technology** subjects, especially everyday technology with strong visual explanations. Do not return to aquatic-life or similar nature topics unless the user explicitly asks.
- Each new topic and visual treatment must be original; do not reuse a previous video's concept or animation unless the user explicitly requests a revision of that video.
- Use the user's selected **`voice-00` exclusively** for narration. Do not substitute another voice or switch voices between sections. Technical QA is not a claim of perceptual realism.
- Favor a clear, restrained documentary delivery with **calmer pacing**. Never speed the source narration up merely to fill a timeline; use fewer words and longer scene holds when a slower feel is requested.
- Produce polished **1080 × 1920** video with legible captions, purposeful motion, quiet music, and restrained sound design.
- Captions should use complete narration-aligned clauses. Do **not** add moving underlines, per-caption progress bars, or timing indicators beneath subtitles.
- Derive captions, scene changes, and sound cues from the exact narration master and verified timing data.
- Validate the encoded MP4: full decode, exact frame count, stream formats, duration, loudness, true peak, silence, and final contact-sheet review including transitions.
- Upload new finished videos to GitHub in **`RESULT/`** on the active Arena branch unless the user explicitly requests another destination. Leave existing Google Drive deliverables unchanged.
